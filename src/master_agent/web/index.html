از گفتگو تا Workflow

ایده‌ات را تعریف کن

بگو ورودی چیست، ایجنت چه کاری انجام بدهد و چه خروجی‌ای می‌خواهی. می‌توانی با پیام بعدی طرح را تغییر بدهی.

طرح را بررسی کن

گره‌ها، اتصال‌ها و خروجی JSON در پنل Workflow آماده می‌شوند. ایجنت‌های این نسخه می‌توانند با Ollama گفتگو کنند؛ حافظه و ابزارهای خارجی هنوز اضافه نشده‌اند.

به n8n بفرست

پس از اتصال n8n، طرح به‌صورت غیرفعال ساخته می‌شود. بازبینی و تأیید فعال‌سازی یک مرحلهٔ جداست.

اتصال n8n

Docker را اجرا کن، در n8n کلید API بساز و آن را در N8N_API_KEY فایل .env بگذار. سپس BisCode را دوباره اجرا کن.

docker compose up -d n8n

BISCODE LOCAL AGENT

ابزارها و اتصال‌های محلی

برای کار با فایل‌ها یا اجرای فرمان، سطح دسترسی همین گفتگو را انتخاب کن. کلیدها و ورود به حساب‌ها از بخش اتصال‌ها مدیریت می‌شوند.

ابزارهای آماده

کاتالوگ گره‌های n8n

فایل خروجی دستور n8n export:nodes را در پوشهٔ پروژه قرار بده تا گره‌های نصب‌شده به کاتالوگ اضافه شوند.

بات تلگرام، حساب شخصی یا یک سرویس HTTP را اضافه کن. اطلاعات حساس رمز می‌شوند و به مدل فرستاده نمی‌شوند.

افزودن اتصال

این دو مقدار را از بخش API development tools در my.telegram.org دریافت کن. ورود با شماره و کد، بعد از ثبت اتصال انجام می‌شود.

ورود به حساب شخصی

ابتدا Workflow را در پنل کناری بساز، به n8n بفرست و پس از بازبینی فعال کن. سپس آن را به اتصال تلگرام وصل کن.

برای حساب شخصی انتخاب گفتگو ضروری است. برای بات، خالی‌گذاشتن یعنی همهٔ گفتگوهای بات.

اولین شروع حساب شخصی از پیام‌های جدید ادامه می‌دهد؛ تاریخچهٔ قدیمی خودکار پردازش نمی‌شود.

فعالیت ابزارها و وضعیت تحویل پیام‌ها ثبت می‌شود. نتیجهٔ نامشخص دوباره به‌صورت خودکار ارسال نمی‌شود.

کلیدهای اصلی در اختیار مدل نیستند.
